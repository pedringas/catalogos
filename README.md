# CatalogPro

Generador de catálogos PDF profesionales desde Excel.

## ✨ Características
- Sube tu planilla Excel/CSV con productos
- Sube las imágenes de cada producto
- Elige entre diseños: Minimalista o Mar-Plast
- Vista previa interactiva del catálogo
- Exporta a PDF de alta calidad con índice clickeable

## 🚀 Uso
Abrí `index.html` en tu navegador. No requiere instalación ni servidor.

## 🔒 Privacidad
Todos los datos se procesan localmente en tu navegador. No se almacena ni envía información a ningún servidor.
